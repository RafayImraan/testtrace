Welcome to ShopEase (System Under Test)

This is a deliberately small e-commerce app with intentional bugs to demonstrate the automation module.

  • Login: user@shop.local / User@123 , admin@shop.local / Admin@123
  • Products API: GET /api/products?q=mouse
  • Cart API: POST /api/cart { productId, qty }
  • Checkout API: POST /api/checkout { items, address, coupon }
  • Health: GET /api/health

Intentional bugs are enabled when BUG_MODE=true: empty product search 500s, checkout FAIL coupon 500s, cart total off by 1 when qty>3, login admin random 500.
